# Fonts

The SVG cards embed two open-source typefaces:

- **Space Grotesk** by Florian Karsten — [source](https://github.com/floriankarsten/space-grotesk)
- **JetBrains Mono** by JetBrains — [source](https://github.com/JetBrains/JetBrainsMono)

Both are licensed under the SIL Open Font License 1.1. The license texts are
included alongside the font files (`OFL.txt` and `OFL-JetBrainsMono.txt`).
